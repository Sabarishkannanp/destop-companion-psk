# PSK timing dashboard and repaired builds

Run `PskCompanion.exe` in the project folder for the avatar and timing dashboard, or `Buddy.exe` for the walking companion and tray dashboard. Both executables include their avatar assets. Existing profiles named Selva or PDK migrate to PSK; other custom names, tasks, and statistics are retained.

In **PskCompanion**, use **When should PSK appear?** to set your name, automatic reminders, startup visibility, repeat interval (1–1440 minutes), active hours, next appearance date/time. Click **Save timing and name**. Set a task's exact appearance in **Task appearance times**, then click **Save task times**. Dates use `yyyy-MM-dd HH:mm` and local Windows time. The schedule checks every five seconds. Equal start/end hours mean all day; overnight windows are supported. Disable startup visibility if the avatar should appear only for scheduled reminders. **Done** completes the announced task; **Later** snoozes for ten minutes. An unanswered reminder stays on screen until you choose an option; other due reminders wait. After Done/Yes or Later, the character reacts for two seconds, then exits within three seconds, including at the slowest walking setting. The dashboard must stay running for scheduled reminders.

In **Buddy**, the dashboard opens at launch. Use **My Tasks** to enter your own task, optionally check **Show character at**, select a date and enter a 24-hour `HH:mm` time, then click **Add Task**. To edit existing schedules, open **Reminders** in the dashboard, edit the interval, active hours, message and **Next appearance**. Set task-specific times in the task schedule table, then **Save appearance times**. Blank task dates disable timed delivery. Scheduled tasks are checked every five seconds and respect Buddy's pause/idle/lock/fullscreen suppression. The **Summon** button previews a real reminder without blocking the automatic scheduler.

The startup crash was caused by converting PNG/DrawingImage tray sources to icons. Buddy now uses a native ICO, with a native system icon fallback. Bundled assets are extracted on first use into `%LocalAppData%\Buddy\Assets` or `%LocalAppData%\PskCompanion\Assets`; files already there are retained for customization. Avatar-folder buttons open these writable folders. In PskCompanion, **Choose Any Photo from Computer** saves your image choice across restarts.
